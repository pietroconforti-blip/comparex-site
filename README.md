# CompareX

Student offers for Vienna and Milan — housing, mobile, transport, gyms, and streaming — compared in one place, then bundled into a monthly package.

This is the current site built in the app preview. It is separate from the existing Next.js app in [compareX](https://github.com/pietroconforti-blip/compareX).

## Scripts

- `npm run dev` — local dev server
- `npm run build` — production build
- `npm run preview` — serve the production build
